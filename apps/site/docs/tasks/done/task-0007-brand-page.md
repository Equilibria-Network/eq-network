## Outcome

`/brand` is the single public visual-identity reference. It combines the measured drawing structure,
restrained graph-paper texture, hatched components, solid technical tooltips, the selected symmetric
Lorenz-derived mark, Space Grotesk display type, and IBM Plex Mono annotations.

The rejected `/brand/*` prototype gallery routes and unused mark experiments were removed. The retained
mark family is generated by `scripts/gen-lorenz-mark.mjs` and includes primary, reversed, accent, and
outline treatments.

## Done when

The public site exposes one complete brand page, one selected mark family, downloadable assets, colour and
type guidance, signature motifs, applied components, and usage rules.

## Revisit when

Reopen this work only when applying the identity to a real page reveals a concrete missing rule or when the
organisation intentionally changes its visual identity.
