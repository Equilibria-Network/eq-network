# Decide and add a LICENSE

- Provenance: audit-0005
- Links back to: `../audits/2026-07-28-audit-0001-inherited-recon.md` (F5)
- Status: done — MIT chosen; `LICENSE` added (`Copyright (c) 2024-2026 Equilibria Network`)
- Owner: unassigned
- Priority: —

## Problem

The public repository has no LICENSE file. By default that is all-rights-reserved: others may not reuse
the code or content. If reuse is intended, a license must say so; if not, the current state may be
deliberate.

## Done when

The owners have decided the licensing intent and either added a LICENSE file or recorded here that
all-rights-reserved is intentional.

## Notes

Owner decision, not an engineering fix. Content (research prose, images) and code may warrant different
terms.
